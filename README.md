# Rays — JEE Preparation Platform

This repository will host a JEE preparation platform inspired by Raysbook.live and Matq.in. Phase 1 focuses on a working frontend (React + Vite) with demo data, a PDF viewer, PYQ browser, practice interface, bookmarks, search, dark mode, and basic progress tracking.

This initial commit was created by Copilot on behalf of the repository owner.
