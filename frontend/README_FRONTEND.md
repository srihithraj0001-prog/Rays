# Rays Frontend (Phase 1)

This is the Phase 1 frontend for the Rays JEE preparation platform.

Run locally:

cd frontend
npm install
npm run dev

This starts the Vite dev server at http://localhost:5173

What is included:
- Dashboard
- Subjects list (syllabus.json)
- PYQ browser with demo questions
- Practice interface
- PDF library (external sample PDF)
- Dark mode (skeleton in CSS)

This is Phase 1 — no backend yet. All user state (bookmarks, notes, progress) is stored in localStorage.
