# Rays Frontend — Phase 1

This is the Phase 1 frontend for the Rays JEE preparation platform. It uses Vite + React and stores user state locally (localStorage).

Key features included in this push:
- Dashboard
- PYQ browser (demo dataset)
- Practice interface
- PDF library with PDF.js viewer (sample legal PDF)
- Dark mode support
- Local bookmarks/notes (localStorage)

Run locally:

cd frontend
npm install
npm run dev

Notes about content and legal:
- I cannot import copyrighted PYQs or PDFs from third-party sites (e.g. matq.in or raysbook.live) without explicit permission from the content owners.
- This push includes demo questions that are clearly labeled as demo and not official.
- The project includes an admin/import tool (placeholder) so you can import PYQs/PDF metadata in JSON/CSV format. If you have permission to use content from any site, provide the exported files (JSON/CSV) with source metadata and I can import them for you.

If you want me to proceed with importing content from a third-party site, please either:
- Provide explicit written permission from the content owner, or
- Provide the exported files (JSON/CSV) that you own or have rights to publish, or
- I can instead add only links/backlinks to the third-party content rather than hosting it.
